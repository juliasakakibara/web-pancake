Size

L1 size scale — used across spacing, padding, gap, heights, widths, and (via reference) border-widths. Built on a 4px base grid with a 2px sub-grid; --lb-size-hairline (1px) and --lb-size-theme (1.6px) are the only values off both grids. Use --lb-size-2x (8px) for intra-element spacing, --lb-size-4x (16px) for element-to-element, --lb-size-6x (24px) for sections. Includes the theme-editable --lb-size-theme — default 1.6px, backs the L2 --lb-border-width-action and is runtime-mutable via the theme editor's Action stroke knob.
