Chat × Timeline composition

Slice 11 of the AI Chat arc. This page demonstrates the composition pattern: a compact composer summoned as a popover, anchored to a timeline selection. It drives generation against the currently-selected region.

Two pieces ship in this slice:

  • LB.Timeline gains a lb-timeline-selection event — fires on drag-end with the selection's viewport-relative rect plus inSec / outSec / duration.
  • LB.openComposerPopover(opts) — new factory in js/components/lb-chat-composer-popover.js. Builds a compact LB.Composer inside an .lb-popover surface, anchored to a rect, with optional context chip + tools + models + prefill. Returns {el, composer, close(), reposition(anchor)}.

Per the pluggable-engine rule, this module ships only the chrome + state machine. The consumer wires submissions to their own backend — stem generation, voice conversion, whatever the product does.

Live demo

Drag the in/out handles to select a region. On drag-end, a compact composer popover appears anchored to the selection mid-point, with the selection range as a context chip. Type a prompt and submit — the demo logs the submission. The popover closes on Esc, outside click, or after submit.

Composer popover API

A single factory. No auto-init — the popover is summoned imperatively in response to a selection event:

const handle = LB.openComposerPopover({
  anchor:        rect,                          // Element | DOMRect | {x,y,width,height}
  placement:     'bottom',                      // or 'top'
  prefill:       '',
  placeholder:   'Ask about this selection…',
  contextChip:   { label: '0:30 → 1:00', kind: 'context' },
  tools:         [{ id: 'web', label: 'Web', icon: 'globe' }],
  models:        [{ id: 'fast', label: 'Fast' }, { id: 'pro', label: 'Pro' }],
  currentModel:  'fast',
  commands:      [/* …same shape as composer.registerCommand */],
  ariaLabel:     'Compose message about selection',
  autoCloseOnSubmit: true,
  onSubmit(value, ctx) {
    // ctx = { contextChip, anchorRect, model }
    callMyBackend(value, ctx);
    // return false to keep the popover open
  },
  onClose() { /* cleanup */ },
});

// Imperative control
handle.composer.setValue('Pre-fill more text');
handle.reposition(newAnchor);
handle.close();

Wiring — Timeline → Popover

~20 lines of glue — listen for the selection event, summon the popover with the rect as anchor, hand the submission off to your backend:

const timeline = document.getElementById('demo-timeline');

timeline.addEventListener('lb-timeline-selection', (e) => {
  const { rect, inSec, outSec } = e.detail;
  LB.openComposerPopover({
    anchor: rect,
    contextChip: {
      label: fmt(inSec) + ' → ' + fmt(outSec),
      kind: 'context',
      data: { inSec, outSec },
    },
    placeholder: 'How should this region change?',
    onSubmit(value, ctx) {
      // Hand off to the consumer's backend. Selection range arrives
      // in ctx.contextChip.data.
      myStemGenerator.queue({
        prompt:  value,
        inSec:   ctx.contextChip.data.inSec,
        outSec:  ctx.contextChip.data.outSec,
      });
    },
  });
});

function fmt(sec) {
  const m = Math.floor(sec / 60);
  const s = Math.floor(sec % 60).toString().padStart(2, '0');
  return m + ':' + s;
}

Anchoring patterns

The anchor option accepts three shapes:

  • Element — getBoundingClientRect() is read automatically. Use this when the anchor IS a real DOM node (a selected chip, a button).
  • DOMRect — pass an existing rect (e.g., from Selection.getRangeAt(0).getBoundingClientRect() for a text selection on a canvas surface, or the rect carried by lb-timeline-selection).
  • Plain object with {x, y, width, height} — useful when you want a virtual anchor (a pointer position on a custom canvas, an SVG coordinate translated to viewport coords).

Placement is 'bottom' by default (docks below the anchor with an 8px gap). Pass 'top' to flip. The popover is clamped to the viewport — if it would overflow, it shifts inward with an 8px margin.

Composer features stay intact

The popover hosts the SAME LB.Composer engine as the standalone composer — not a parallel reimplementation. So the slash command palette, the chips row, the tools strip, the model selector, the mic affordance, drag-and-drop file handling, autosize, ⌘/Ctrl + Enter to send — all of it is available. The popover variant just defaults to the slim layout (no footer when tools/models aren't configured) so it stays anchored without overwhelming the surface.
