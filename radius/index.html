Radius

Corner radius primitives (L1) and semantic aliases (L2) for interactive, field, surface, overlay, badge, and full/pill shapes. The theme editor's radius control is a four-option segmented picker (Square, Soft, Rounded, Pill) that remaps the L2 aliases to different L1 primitives, so every component changes shape together.
